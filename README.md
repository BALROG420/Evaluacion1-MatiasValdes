## Instalación

### 1. Crear entorno virtual:

```
python3 -m venv venv
```

Linux/Mac:
```
source venv/bin/activate
```

Windows:
```
venv\Scripts\activate
```

### 2. Instalar dependencias:

```
pip install -r requirements.txt
```
